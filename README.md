Quality Assurance portfolio with real manual web & mobile testing artifacts: test plan, test cases, bug reports, exploratory testing, BDD scenarios, and checklists.

Custom-designed static site (HTML + CSS + a touch of JS). No frameworks, no build step.

## Como publicar no GitHub Pages (passo a passo)

1. Crie uma conta no [github.com](https://github.com) (se ainda não tiver).
2. Clique em **New repository** (botão verde) e nomeie como `qa-portfolio`. Deixe **Public** e clique em **Create repository**.
3. Na página do repositório, clique em **uploading an existing file** (ou `Add file > Upload files`).
4. Arraste **todo o conteúdo desta pasta** (arquivos `.html`, `style.css`, `script.js`, `.nojekyll` e as pastas `assets` e `pt`) para a área de upload e clique em **Commit changes**.
5. Vá em **Settings > Pages** (menu lateral esquerdo).
6. Em **Source**, escolha **Deploy from a branch**; em **Branch**, selecione `main` e pasta `/ (root)`. Clique em **Save**.
7. Aguarde 1–2 minutos. Seu site estará em `https://SEU-USUARIO.github.io/qa-portfolio/`.

💡 Para ver o site antes de publicar, é só dar dois cliques no `index.html` — abre no navegador com tudo funcionando.
